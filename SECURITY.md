# Security Policy

## Supported Versions

supported versions for bug fixes

| Version | Supported          |
| ------- | ------------------ |
| main    | ✅, only packages and tools |
| 1.3.x   | :white_check_mark:, kernel and drivers included |
| 1.2.0   | :white_check_mark:, default userland only |
| 1.1.2   | :white_check_mark:, default userland only |
| < 1.1.0 | :x:, openssl only                |

## Reporting a Vulnerability

Start a new issue with [VULNERABILITY] as its title

in the body describe how to recreate the vulnerability;
what it affects and logs if applicable
